# Casita Cursor Pack — Start Here

## Qué es esto
Este pack está pensado para copiarse dentro del repo de Casita.

Incluye:
- `specs/` → el spec-driven development del producto y la arquitectura
- `.cursor/rules/` → reglas operativas para que Cursor no derive el sistema
- `cursor_master_prompt.md` → prompt maestro para arrancar
- `cursor_kickoff_prompt.md` → prompt corto para iniciar la ejecución real
- `cursor_rules_install.md` → instrucciones para ubicar cada archivo en la carpeta correcta

## Recomendación
No hace falta una “version 2” grande antes de empezar.
Este pack V1.1 ya es suficiente para empezar a desarrollar si:
1. copiás `specs/` al repo
2. copiás `.cursor/rules/` al repo
3. pegás `cursor_master_prompt.md` en Cursor
4. luego pegás `cursor_kickoff_prompt.md`
