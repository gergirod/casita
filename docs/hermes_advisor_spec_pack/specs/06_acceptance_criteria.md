# 06 — Acceptance Criteria

## Advisor pilot is successful if
- complex owner requests improve in quality
- simple flows do not get slower or more expensive unnecessarily
- advisor use is traceable
- no deterministic flow regresses

## Learning loop is successful if
- useful memory/playbook/skill drafts are produced
- drafts are reviewable and understandable
- no draft auto-activates
- repeated operational lessons become easier to reuse

## Immediate red flags
- advisor being called on trivial flows
- retrospective running on every event indiscriminately
- generated drafts becoming noisy or unreviewable
- memory polluting deterministic prompts without scoping
