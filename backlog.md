# Casita — Backlog

## Principles
A feature only moves in when it:
1. supports the owner-first workflow
2. reduces manual follow-up
3. does not turn Casita into a full ERP too early
4. can be explained simply
5. does not add unnecessary compliance or support burden

## Near-term
- WhatsApp reminders
- sender-based bill suggestions
- Mercado Pago recurring rent flow
- better tenant simple history

## Medium-term
- Gmail / Outlook connection
- OCR / bill extraction
- maintenance requests
- richer contract metadata
- shared owner + assistant access

## Long-term
- more payment provider adapters
- more communication adapters
- portfolio analytics
- utility-provider-specific integrations if official APIs exist

## Explicitly reject for MVP
- autopay of third-party utility bills
- full accounting suite
- listing marketplace
- property manager ERP complexity
- bank reconciliation
- legal collections workflow

## Product mantra
If a feature does not clearly help the owner answer:
- what is pending?
- what was paid?
- what proof do I have?
- what do I need to follow up on today?
it probably does not belong yet.
