# Task 01 — Foundations

## Goal
Set up the Vercel-first app shell and core models.

## Deliverables
- Next.js app scaffold
- auth integration
- workspace creation
- property CRUD
- unit CRUD
- tenant contact model
- storage integration base
- app layout

## Acceptance criteria
- owner can sign in
- owner can create workspace
- owner can create property and unit
- owner can add tenant contact
- app is deployable to Vercel
