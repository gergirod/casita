# Task 06 — Bill Ingestion via Forwarding Inbox

## Goal
Convert forwarded bill emails into review items and obligations.

## Deliverables
- inbound email webhook handler
- attachment storage
- incoming bill review table
- owner review screen
- convert review item into obligation
- attach original PDF to obligation

## Acceptance criteria
- forwarded email creates review item
- owner can confirm unit and type
- created obligation shows original file
